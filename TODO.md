Честный список. Закрытый пункт снимается, а его исход записывается в
`CHANGELOG.md` (правило ноль в `CLAUDE.md`).

## Поставка

- [ ] **Подпись exe.** `Pult.exe` и `pult-cli.exe` не подписаны: SmartScreen
  предупреждает при первом запуске скачанного архива.
- [ ] **Linux и macOS не проверялись.** Код разделён `cfg(windows)`
  (Job Object, `explorer.exe`, `PATHEXT`), ветки для других систем
  написаны, но ни разу не собирались и не запускались. CI только на Windows.

## База знаний

- [ ] **Уроки для PHP и Ansible.** Программы есть (`composer`, `php`,
  `phpunit`, `pest`, `ansible-playbook`), но привязаны к общим урокам
  (`terminal`, `testing`, `package-managers`, `deploy`). Своих уроков нет.

## Проверки

- [ ] **Тесты ядра покрывают не всё.** В `core/tests/` есть `ci_config`,
  `explain`, `git_stash`, `kb`, `runner_util`, `scan`, `security`, `store`,
  `sub_engine`. Нет тестов на `topics.rs`, на разбор вывода `--help` в
  `helpcmd.rs` (проверено только согласие на запуск) и на `store.rs` кроме
  сценариев. Терминал (`cli`) и команды окна (`app`) тестов не имеют.
- [ ] **Автотесты окна.** Окно проверяется руками и агентом `ui-qa` через
  порт отладки; снимков-эталонов и прогона в CI нет.

## Настройка разработки

- [ ] **Хуки не включены.** `.githooks/` работают только после
  `git config core.hooksPath .githooks` в каждой рабочей копии; до этого
  действуют глобальные `~/.githooks` (только автор). Включает владелец.
- [ ] **Шаг CI `status.mjs --check` ни разу не шёл на GitHub.** Локально
  зелёный; первый прогон - на первом PR после пуша.
- [ ] **`.claude/worktrees/` не в `.gitignore`.** Рабочие копии агентов внутри
  репозитория видны в `git status` как неотслеживаемые; `git add -A` добавит
  их вложенным репозиторием.
- [ ] **Права на исполнение хуков.** На Windows git зовёт хуки и без бита
  `+x`, на Linux и macOS - нет. При первом коммите: `git add --chmod=+x .githooks/*`.
