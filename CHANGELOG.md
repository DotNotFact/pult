## [Unreleased]

- Урок «ИИ-разработка: агенты, навыки, хуки, MCP» (`ai-dev`): файлы инструкций, правила по путям, субагенты, скиллы, хуки, MCP, права, проверки как контракт и оркестрация агентов; пять заданий для своего проекта.
- Вкладка «ИИ» и команда `pult ai [--json]`: Пульт читает ИИ-часть любого проекта (`CLAUDE.md`, `AGENTS.md`, `.claude/rules`, агенты, навыки, команды, хуки, `.mcp.json`, git-хуки, `.cursor`, Copilot, Windsurf, Gemini, Aider, Continue), рисует схему слоёв, показывает рассказ «как это работает вместе» и объясняет простыми словами, зачем каждая часть нужна и когда срабатывает. Связи берутся только из текста файлов (обратные кавычки, ссылки, путь скрипта в команде хука). Правилу по путям считается, сколько файлов проекта ловит каждый шаблон. Ничего из проекта не запускается, `.env*` не читаются, значения env и токены в командах скрыты. Что за вид детали и что о нём сказать - `knowledge/ai.json`; новый вид - одна запись. Вкладки нет, пока в папке нет признаков ИИ-части. Команда IPC `ai_map`, событие `ai`.

## [2.0.0] - 2026-10-14

Пульт переписан с нуля: ядро на Rust, окно на Tauri 2, терминал на ratatui.

### Добавлено

- Ядро `pult-core`: разбор проекта, движок объяснений, git, CI, запуск
  процессов, хранилище. Окно и терминал работают поверх него одинаково.
- Поиск скриптов: npm/pnpm/yarn/bun, Makefile, justfile, Taskfile, Cargo,
  dotnet, Go, Maven, Gradle, Python, Docker Compose, файлы `.ps1`, `.sh`,
  `.bat`, `.cmd`, `.py` в папках скриптов.
- Объяснение каждого скрипта: что делает, команда по частям, что внутри,
  ключи, что затронет (чтение, запись, удаление, сеть). Источники - база
  знаний, шапка файла скрипта, `package.json` программы в `node_modules`,
  кнопка «Спросить у программы» (разбор `--help`).
- База знаний в `knowledge/`: 193 программы, 25 уроков, эффекты, этапы,
  стек, термины, тексты подсказок. Формат - `knowledge/SCHEMA.md`, проверка -
  `node knowledge/validate.mjs`. База читается с диска без пересборки, иначе
  работает копия, вшитая в exe.
- Окно: Обзор (быстрый запуск, путь по этапам, состояние с кнопками
  исправления), Скрипты (поиск, фильтры, группы, панель с объяснением),
  Документация (уроки по технологиям проекта), Пайплайны (GitLab и GitHub
  через `glab`/`gh`, журнал джобы в консоли окна), Git, История, Консоль
  (цвета ANSI, ввод, поиск, подсветка ошибок, кликабельные localhost).
- Режим обучения: подсказки к терминам, «что происходит внутри», ссылки на
  уроки.
- Минимальный интерфейс (настройки): только кнопки и данные - без подсказок,
  значков «i», описаний в списках и пояснений этапов, плотнее. Противоположность
  режиму обучения: включение одного выключает другое.
- Фильтры скриптов разложены по строкам «Этап», «Показать», «Где».
- «Путь разработки» на «Обзоре» - цепочка этапов без номеров: этап, число
  скриптов, джобы CI, точка состояния (идёт, упал).
- Консоль: вывод частых мелких строк идёт сразу, а не пачкой в конце; ссылки
  localhost целиком, даже если программа красит порт отдельно; заголовки npm не
  считаются ошибками; кнопка ошибок идёт к следующей; поиск сообщает о совпадениях
  в скрытом начале длинного вывода; идущую вкладку можно закрыть (с остановкой).
- «Перезапустить» опасного скрипта спрашивает подтверждение, как и запуск.
- «Сбросить» фильтры очищает и поиск; избранное и «Запущены» обновляются сразу.
- Открытие несуществующей папки не закрывает текущий проект - только сообщение.
- Разбор проверен на 35 настоящих проектах: пути Windows в командах (`gradlew.bat`)
  больше не теряют разделители; описания не режутся посреди фразы и считаются в
  буквах, а не байтах; в .NET-решении restore/build/test берутся у решения, а
  `dotnet run` предлагается только для программ; GitHub Actions с отступом в 4
  пробела и комментарии в YAML разбираются.
- «Спросить у программы» спрашивает справку подкоманды (`git status -h`,
  `cargo check --help`) и саму программу npm-скрипта, а не npm.
- Имя вроде `release-notes` или `deploy:preview` больше не считается опасным
  (исключения - `heuristics.json`, `danger.except`).
- В базе знаний: react-scripts, nswag, exit. Урок «Скрипты оболочки» -
  только если в проекте есть скрипты оболочки.
- Островок-сайдбар слева, светлая, тёмная и автоматическая тема. Узкое окно
  переносит разделы в нижнюю панель.
- Свой заголовок окна вместо рамки Windows: двойной щелчок по значку больше
  не закрывает Пульт. Контекстное меню WebView («Назад», «Обновить») отключено,
  кроме полей ввода. Фон окна повторяет тему - без белых полос при изменении
  размера. Новая палитра: глубокие слои, цвета со смыслом, контраст текста не
  ниже 4,5:1 в обеих темах.
- Нижняя панель узкого окна (до 760 px): разделы с короткими подписями и меню
  «Ещё» (проект, поиск, обучение, виджет, настройки, справка). Клавиши 1-9
  открывают вкладки по порядку.
- Островок больше не мигает у края 1100 px: свёрнутый и развёрнутый вид
  меняются с запасом (1080 и 1120), без перерисовки на каждом пикселе.
- Одна сетка отступов: поле колонки и шкала отступов. Края содержимого,
  консоли, строки состояния, панели подробностей и нижней панели стоят на
  одних вертикалях; раскладка следует ширине колонки, а не окна.
- Виджет: окно меньше 360 x 300 становится карточкой с самым нужным (что
  идёт, быстрый запуск, сценарии, CI, git). Высота подстраивается под
  содержимое, дальше - прокрутка. Сверху своя полоса (за неё перетаскивать) и
  три кнопки: поверх окон, вернуть прежний размер, закрыть; снизу - репозиторий
  и ветка. Пустые блоки не показываются. Включается, когда край окна
  отпустили, а не под мышью; мышкой не растягивается, текст копируется. «Свернуть в виджет» - в островке
  и в меню «Ещё»; блоки и их порядок - в настройках.
- Строка состояния под консолью: проект, ветка, что идёт, последний CI,
  откуда база, размер окна и кнопка «Рекомендованный размер».
- Вкладка «Сценарии»: свои цепочки команд проекта одной кнопкой, ход по шагам,
  запуск из меню значка в трее. «Создать популярные сценарии» подбирает
  готовые цепочки по скриптам проекта.
- Сколько ещё: у идущего скрипта, сценария, пайплайна и джобы - «≈ ещё 2 мин»
  или «дольше обычного на 1 мин» и тонкая полоска. Оценка - середина прошлых
  успешных запусков; меньше двух - оценки нет.
- Навигация по уроку: липкая полоса разделов с подсветкой текущего, список
  «Все разделы», кнопка «Наверх» у длинных страниц.
- Панель подробностей поверх узкого окна - с лёгкой подложкой, нажатие на
  неё закрывает панель. Длинный список ключей - «Показать все» вместо
  прокрутки внутри панели. Подсказки в узкой колонке - строкой «?»,
  раскрываются по нажатию. «Перенос» в консоли - явный переключатель.
- Перерисовка по событиям git и проекта меняет только изменившиеся узлы:
  нажатие кнопки не теряется, поле ввода не теряет фокус.
- Короткое движение: всплывающие окна, палитра, справка, панель подробностей,
  сообщения, смена вкладки и урока, консоль, подсказки и ответ на вопрос
  появляются и уходят за 120-200 мс (только прозрачность и сдвиг). При
  «уменьшить движение» в Windows и при первой отрисовке - сразу, без движения.
- Цифры шагов и значки на цвете урока - тёмные или белые, что контрастнее:
  на жёлтом и светло-зелёном они теперь читаются.
- Схемы в уроках не ужимаются мельче натурального размера: если схема слева
  направо не помещается, Пульт рисует её сверху вниз. Стрелка, замыкающая
  цикл (`docker pull` обратно в образ), рисуется дугой и не ломает раскладку,
  подписи стрелок не налезают на блоки и друг на друга.
- Новые разделы уроков: «код рядом» (C# и IL, до и после), «Попробуйте сами»
  (задание, проверка, подсказка, решение), «Как правильно» (делайте, не
  делайте, когда применять), группы в шпаргалках.
- Глубокие уроки по WSL, Docker Engine, Docker, Docker Compose, CI/CD,
  GitHub, .NET и внутреннему устройству C# (GC, async state machine, IL).
- Порядок уроков - в `knowledge/lessons.json`, а не в коде.
- Свои полосы прокрутки, переключатели, выпадающие списки и раскрывашки
  вместо стандартных Windows, в цветах темы.
- Версия и описание проекта на Rust берутся из `Cargo.toml`, включая общий
  `[workspace.package]`. Быстрый запуск находит `cargo run`, `dotnet test`
  и похожие команды, а не только скрипты `package.json`.
- Перетаскивание папки в окно, один экземпляр окна на второй запуск ярлыка,
  слежение за файлами проекта с фоновым перечитыванием.
- Терминал `pult`: интерактивный экран и команды `info`, `ls`, `explain`,
  `run`, `ci`, `learn`, `ui`.
- Настройки, история запусков и кэш в `%LOCALAPPDATA%\dev.dotnotfact.pult\data`.
- Установщик `Pult_2.0.0_x64-setup.exe`: ставит на одного пользователя без
  прав администратора в `%LOCALAPPDATA%\Programs\Pult`, ярлык в «Пуск»,
  по флажкам - ярлык на рабочем столе и команда `pult` в PATH, сам ставит
  WebView2, если его нет. Обновление поверх сохраняет настройки и историю.
  Удаление закрывает Пульт, убирает ярлыки, PATH, автозапуск и значок трея и
  спрашивает, удалить ли настройки, историю и кэш (тихо: `/S` оставляет,
  `/S /WIPEDATA` удаляет). Переносный zip остался; в релизе к ним
  `SHA256SUMS.txt`. `pult.cmd` и в установке, и в zip лежит в `bin\`:
  рядом с `Pult.exe` команда `pult` открывала окно вместо терминала.

- `pult-cli.exe` собран со статическим рантаймом Visual C++ - запускается на
  чистой Windows; обрезанный вывод (`pult info | Select -First 2`) больше не
  роняет программу.
- Окно не возвращает системную рамку из сохранённого состояния: плагин
  положения окна помнит место и размер, но не рамку.
- Окно тянется и за верхний край заголовка (у окна без рамки Tauri даёт только
  бока и низ), у кнопок заголовка - курсор-рука.
- `pult-cli` в файл, в канал или при `NO_COLOR` пишет чистый текст без кодов
  цвета; в `pult info` у GitHub Actions - имя workflow и его джобы.
- Блоки на «Обзоре»: каждый раздел (быстрый запуск, путь разработки, состояние,
  технологии, последние запуски, документы) - карточка из одного реестра
  (`ui/blocks.js`, `Blocks.register`). Блок перетаскивается за шапку на новое
  место (соседи плавно съезжают), сворачивается, прячется и возвращается кнопкой
  «Блоки», меняет ширину (вся, половина, треть); с клавиатуры - стрелки на ручке
  и меню «⋯». Порядок, свёрнутые, скрытые и ширина запоминаются (localStorage).
  Сетка - 1, 2 или 3 колонки по ширине, без дыр. Разделы Git, «Пайплайнов»,
  «Истории» и карточки сценариев - та же карточка с той же шапкой.
- `tools/cdp.mjs check` мерит ряды: у соседей одной строки совпадают средние
  линии (ряд по центру), верхние края и высоты (ряд карточек) с точностью 1 px,
  края шапки, блоков и консоли стоят на линиях сетки.

### Безопасность

- Команды запускаются без оболочки, списком аргументов.
- git вызывается с `core.fsmonitor=false`, `log.showSignature=false`,
  `protocol.allow=never`. До первого вызова Пульт сам читает `.git/config`:
  фильтры, `gpg.program`, include и похожее делают репозиторий «не
  доверенным» - git не запускается до кнопки «Доверять этому репозиторию».
  Сетевой путь в gitdir, alternates или настройках - отказ.
- «Спросить у программы» запускает файл из проекта только после
  подтверждения с полным путём; справка идёт из папки данных Пульта.
- Адрес remote проверяется (`owner/repo`), `gh` и `glab` получают хост явно.
- Ссылки и junction в проекте не обходятся; «Проводник» открывает только
  папки; база знаний ищется только рядом с exe.
- Остановка по тайм-ауту гасит всё дерево процессов, а не только первый.
- Остановка гасит всё дерево процессов через Job Object.
- Запросы CI только к доверенным хостам.
- Документы открываются программой по умолчанию только с текстовыми
  расширениями; `.env` не читается; сетевые (UNC) пути не открываются.
- Окно без сервера и порта, CSP только на свои скрипты.

### Изменено

- Разбор проекта быстрее и легче: каждая папка читается один раз, git идёт
  параллельно с объяснениями, правила подкоманд собираются крейтом regex.
  Повторный разбор большого монорепозитория - 151 мс -> 40 мс, куча после
  первого разбора - 14,9 МБ -> 12,5 МБ. Окно: сетевая служба WebView2 внутри
  процесса браузера (на один процесс меньше). Замеры - `docs/optimizations.md`.
- Консоль - островок на фоне страницы: без своей заливки и тени, с отдельной
  рамкой цвета `--console-edge`, полем вокруг и внутри; шапка, строка команды и
  вывод начинаются на одной вертикали. Ручка высоты - серая планка во внутреннем
  поле вместо синей линии на рамке. В узкой консоли «развернуть» и «свернуть»
  стоят в строке вкладок.
- Шапка страницы - сетка: проект и кнопки на одной средней линии, строкой ниже
  раздел, версия, ветка и свежесть разбора, ниже описание в две строки с «ещё».
- «Состояние» на «Обзоре» - список строк с точкой на линии заголовка вместо
  карточек разной высоты; стрелка пути разработки больше не начинает строку.
- Вкладка Git у недоверенного репозитория пишет «git не запускался», а не
  «Всё закоммичено» и «Коммитов нет».

### Исправлено

- Доступность: всё окно управляется с клавиатуры, фокус не теряется при
  перерисовке и возвращается из диалогов и панелей; у кнопок-значков есть
  подписи для экранного диктора, о запусках объявляется голосом; статусы
  различаются формой, а не только цветом; зоны нажатия не меньше 24 px.
- Длинные уроки и консоль рисуются быстрее (`content-visibility`): урок C# -
  6 мс до первого кадра вместо 15, перерисовка консоли - 20-24 мс вместо 53-80.

- Сбой в одном фоновом потоке больше не останавливает всё окно: блокировки
  переживают панику, запись истории идёт вне общей блокировки.
- Сценарий, чей поток упал, не остаётся навсегда «идёт».
- `pult-cli`: длительность 119,6 с показывается как «2 м 0 с», а не «1 м 60 с»;
  пустая дата из `glab` больше не роняет программу.

- Виджет, закреплённый поверх окон, после перезапуска Пульта снова поверх окон.
- Свернули в виджет развёрнутое на весь экран окно - «Вернуть прежний размер»
  снова разворачивает его, а не ставит окно размером с экран.
- Окно, которому Пульт меняет размер (виджет растёт под содержимое, «Вернуть
  прежний размер»), не уходит под панель задач и за правый край экрана.
- Меню значка в трее показывает «идёт» и у сценария, запущенного из окна, и
  снимает пометку, когда сценарий закончился.
- `pult ui .` при уже открытом Пульте открывает папку, где команду набрали,
  а не папку первого запуска.
- «Сворачивать в трей» без значка в трее (старая оболочка Windows) больше не
  прячет окно безвозвратно: крестик закрывает Пульт.
