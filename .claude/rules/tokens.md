# Экономия токенов без вреда работе

Дорого не написать код, а перечитывать контекст: каждый лишний ход
перечитывает всю сессию. Замер Истока (`tools/session-stats.mjs` там,
здесь - `.claude/scripts/session-stats.mjs`): больше половины прогонов
проверок шли без единой правки между ними, контекст - сотни тысяч токенов
на ход.

## Пять правил

1. **Проверка - только после правки.** Полный набор гейтов - один раз перед
   коммитом. При отладке - адресно: один тест, один файл базы.
2. **Снимок окна читается один раз**, вывод записывается текстом. Снимок
   живёт в контексте до конца сессии.
3. **Правки - инструментами Edit и Write**, а не `node -e`, `sed -i` или
   `cat >`: текст с обратными кавычками в `node -e "..."` исполняется как
   скрипт.
4. **Одна задача - одна сессия.** Сессию закрыть до сжатия контекста:
   передача делами (`TODO.md`, `docs/decisions.md`) дешевле.
5. **Рутина - субагентам на модели проще** (`model: sonnet` или `haiku`):
   поиск, прогон гейтов, сбор данных. Сильная модель - план, враждебное
   ревью, безопасность, отладка. Общий бриф агентам - файлом в scratchpad,
   а не повтором в каждой постановке. Отчёт владельцу - вехами, не каждым
   уведомлением.

## Что гонять под какую правку

| Правка | Команда |
|---|---|
| `*.md`, `docs/**`, `TODO.md` | тире в изменённых файлах (`CLAUDE.md`, шаг 4); `node tools/status.mjs --check`, если менялись правила, агенты, скиллы |
| `knowledge/**` | хук сам гоняет `validate.mjs` по файлу; перед коммитом - `node knowledge/validate.mjs` целиком |
| `core/src/**` | `cargo test -p pult-core`, `cargo clippy -p pult-core --all-targets -- -D warnings` |
| `app/src/**` | `cargo clippy -p pult-app -- -D warnings`; новая команда IPC - `node tools/status.mjs` |
| `cli/**` | `cargo clippy -p pult-cli -- -D warnings` |
| `ui/**` | `node tools/cdp.mjs check` на трёх ширинах (скилл `pult-ui`); палитра - `node tools/contrast.mjs` |
| `.githooks/**`, `tools/status.mjs` | `node .claude/scripts/verify-gates.mjs` |
| перед коммитом, любая правка кода | четыре гейта из `CLAUDE.md` и `node tools/status.mjs --check` |

`cargo fmt --all --check` дешёвый - его можно всегда.

## Замер своей сессии

`node .claude/scripts/session-stats.mjs` - транскрипты этого проекта:
средний контекст на ход, прогоны проверок без правок между ними, файлы,
прочитанные 3+ раза, команды, запущенные 5+ раз. Цель: проверок без правки
меньше 15%.
