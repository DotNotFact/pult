# Правила общения

В issue, pull request и обсуждениях проекта действуют простые правила.

- Обсуждаем код и решения, а не людей.
- Новичок здесь желанный гость. Пульт и сделан для тех, кто только учится,
  поэтому «глупых вопросов» тут не бывает.
- Без оскорблений, травли, угроз и чужих личных данных.
- Не согласны - объясните почему и предложите вариант.

За основу взят [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Если кто-то нарушает правила, напишите владельцу репозитория
[в Telegram](https://t.me/dotnotfact). Сообщения, которые нарушают правила,
удаляются, а их авторы могут потерять доступ к проекту.
