# Пульт

Открываете папку любого проекта - Пульт находит всё, что в нём можно запустить, и объясняет простыми словами:
что делает команда, из каких частей она состоит, какие ещё есть ключи, что произойдёт при запуске и что происходит внутри.
Рядом - уроки по технологиям проекта (git, Docker, CI/CD, .NET, Node и другие) со схемами, графиками и вопросами.

Одна программа - два лица:

| | Что это | Как открыть |
|---|---|---|
| **Окно** | настольное приложение `Pult.exe` (Tauri 2 + Rust) | ярлык «Пульт» или `pult ui` |
| **Терминал** | `pult.exe` с интерфейсом на ratatui и командами | ярлык «Пульт - консоль» или `pult` в папке проекта |

## Главное правило: знания - в данных, не в коде

Все пояснения лежат в `knowledge/` в JSON. Код только читает их и применяет к любому проекту одинаково.
Ни одного правила под конкретный проект нет. Нужно новое пояснение - добавляется в JSON и работает везде.
Формат и правила текста - `knowledge/SCHEMA.md`, проверка - `node knowledge/validate.mjs`.

Откуда берутся пояснения, все офлайн:

1. **База знаний** - 193 программы: что делают, подкоманды, ключи, что происходит внутри.
2. **Сам файл скрипта** - шапка-комментарий, ключи из кода, признаки записи, удаления, сети.
3. **Пакет программы** в `node_modules` - описание от авторов, если программы нет в базе.
4. **Справка программы** - кнопка «Спросить у программы» запускает `--help` и разбирает все ключи.

## Режим обучения

Включается в настройках окна. Термины в тексте подчёркиваются и раскрываются по наведению,
у каждого скрипта открыт блок «что происходит внутри», у значков - пояснение «зачем это знать»,
у программ - ссылки на уроки.

## Окно

- **Обзор** - быстрый запуск, путь разработки по этапам, состояние с кнопками исправления, технологии проекта.
- **Скрипты** - поиск, фильтры с подсчётом, группировки. Клик по строке - панель: что делает, команда по частям,
  что внутри, что произойдёт, ключи, «спросить у программы», уроки, прошлые запуски.
- **Документация** - уроки по найденным технологиям: схемы, термины, шаги, примеры, сравнения, графики, частые ошибки,
  шпаргалка, вопросы и скрипты вашего проекта, где это работает. Остальные 22 урока - по кнопке.
- **Пайплайны** - статус GitLab/GitHub, этапы и джобы; журнал джобы - в консоли окна, без браузера.
- **Git** и **История**.
- **Консоль** - цвета ANSI, полосы прогресса не размножаются, ошибки подсвечены и посчитаны, ссылки localhost кликабельны,
  ввод для процесса, поиск по выводу.
- Перетащите папку в окно - она откроется. Второй запуск ярлыка не плодит окна.

## Терминал

```
pult                     интерактивный экран: Обзор, Скрипты, CI, Уроки, Проекты
pult info                сводка
pult ls [поиск]          скрипты с объяснениями (--stage check)
pult explain <скрипт>    что делает, команда по частям, что внутри, ключи
pult run <скрипт> -- арг запуск с выводом прямо в терминал, код выхода сохраняется
pult ci [номер]          пайплайны и джобы; pult ci log <джоба>
pult learn [урок]        уроки прямо в терминале
pult ui [путь]           открыть окно
```

## Безопасность

- Нет сервера и открытого порта: окно говорит с ядром через IPC Tauri.
- Команды запускаются без оболочки, списком аргументов: имя файла или аргумент не станет второй командой.
- git вызывается с выключенным fsmonitor: чужой `.git/config` не запустит свою программу при открытии папки.
- Остановка гасит всё дерево процессов через объект задания Windows.
- Документы открываются программой по умолчанию только с текстовыми расширениями.
- Запросы CI уходят только на доверенные серверы (gitlab.com, github.com и то, что вы добавите в настройках).
- `.env` не читается, сетевые папки не открываются, CSP запрещает чужие скрипты в окне.

## Скорость

| Что | Сколько |
|---|---|
| Загрузка базы знаний | ~17 мс |
| Разбор крупного проекта (105 скриптов с объяснениями) | ~190 мс, из них ~140 мс - git |
| Повторное открытие | из кэша мгновенно, свежий разбор фоном |

Регулярные выражения компилируются один раз, правила подкоманд - только для программ, которые встретились в проекте.

## Устройство

| Папка | Что внутри |
|---|---|
| `core/` | ядро на Rust: разбор, движок объяснений, git, CI, запуск процессов, хранилище |
| `app/` | окно Tauri: команды для интерфейса, события, слежение за файлами |
| `cli/` | терминальная версия на ratatui |
| `ui/` | интерфейс окна: `app.js`, `learn.js`, стили |
| `knowledge/` | база знаний и проверялка |
| `bin/` | собранные `Pult.exe` и `pult.exe` |
| `data/` | недавние проекты, избранное, настройки, история, кэш |

Сборка: `cargo build --release`, затем `pwsh -File make-shortcut.ps1` - он кладёт exe в `bin/` и ярлыки на рабочий стол.
