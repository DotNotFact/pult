# ADR 0003 - Запуск без оболочки и защиты при открытии чужой папки

**Статус:** принято владельцем 13.10.2026 · **Затрагивает:** `core/src/runner.rs`,
`git.rs`, `ci.rs`, `scan.rs`, `app/src/main.rs` (`open`), `ui/`

## Контекст

Пульт открывает папки, которым нельзя доверять: скачанный репозиторий,
архив, проект коллеги. Имена файлов, `package.json`, `.git/config`, вывод
программ - данные злоумышленника. Открытие папки и щелчок «Запустить» не
должны запускать ничего, кроме выбранной команды, и не должны отдавать
токены.

## Решение

1. **Без оболочки.** Программа и аргументы передаются списком
   (`runner::spawn_live`, `capture`). Скрипт сразу собирается в список:
   `npm run <имя>`, `make <цель>`, `bash <файл>`; аргументы, которые
   пользователь дописал в окне, делятся на слова (`shell-words`), а не
   отдаются `cmd /c` или `sh -c`. Имя файла вида `a & del ...` остаётся
   одним аргументом.
2. **git с `-c core.fsmonitor=false`** и выключенным `untrackedCache`:
   `core.fsmonitor` в чужом `.git/config` запустил бы любую программу при
   первом же `git status`.
3. **Остановка через Job Object:** гаснет всё дерево потомков.
4. **CI только к доверенным хостам** (`heuristics.ciHosts` и настройки):
   иначе remote из чужого `.git/config` получил бы токен `glab`/`gh`.
5. **Документы открываются программой по умолчанию только с текстовыми
   расширениями** (`heuristics.docExtensions`), остальное - в редакторе.
6. **Сетевые (UNC) пути не трогаем**, `.env` не читаем, пути `open` только
   внутри проекта.
7. **Окно без сервера и порта**, CSP только на свои скрипты, порт отладки
   только в debug-сборке.

## Рассмотренные варианты

| Вариант | Почему не он |
|---|---|
| `cmd /c <строка>` как в терминале | склейка аргументов, `&`, `|`, `%VAR%` из данных проекта становятся командами |
| Спрашивать подтверждение перед каждым запуском | не защищает от fsmonitor и UNC: они срабатывают до любого запуска |
| Разрешить CI к любому хосту из remote | токен уходит на адрес, который выбрал автор папки |

## Последствия

- Скрипты, которым нужна оболочка (конвейеры `|`, `&&` внутри
  `package.json`), работают как прежде: их запускает менеджер пакетов или
  интерпретатор файла, а Пульт передаёт ему только имя скрипта.
- Новый способ запуска или чтения - только через `runner` и `git.rs`;
  `security-reviewer` проверяет это на каждом диффе.
- Список защит и где они живут - `.claude/rules/security.md`.
