# ADR 0002 - Знания в данных: `knowledge/*.json`, ни одного правила в коде

**Статус:** принято владельцем 13.10.2026 · **Затрагивает:** `knowledge/`,
`core/src/kb.rs`, `explain.rs`, `scan.rs`, `topics.rs`, `ui/`

## Контекст

Ценность Пульта - объяснения: что делает команда, что значит ключ, что
происходит внутри. Таких фактов тысячи, и они растут с каждой новой
программой. Если они живут в коде, каждое новое пояснение - пересборка, а
код обрастает условиями «если команда начинается с ...». Владелец сильно
презирает хардкод и правила под конкретный проект: Пульт должен одинаково
работать на любой папке.

## Решение

1. **Все знания - в `knowledge/*.json`:** программы и подкоманды
   (`tools/`), уроки (`topics/`), эффекты, этапы и слова-признаки,
   стандартные команды манифестов, признаки стека, документы корня, тексты
   подсказок, термины, значки, общие списки (`heuristics.json`).
2. **Код только применяет данные.** Разбор форматов файлов (`package.json`,
   `Makefile`, YAML CI) - код; смысл найденного - данные.
3. **Ни одного правила под конкретный проект.** Признаки - общие (файл,
   зависимость, команда), примеры - `my-app`, `api`, `web`.
4. **Формат описан в `knowledge/SCHEMA.md`, проверяется
   `knowledge/validate.mjs`:** схема, ссылки между файлами, запрещённые
   тире и слова. Проверка входит в CI и в хук агента.
5. База читается с диска (правка без пересборки, кнопка «Перечитать»),
   иначе - копия, вшитая в exe (`include_dir!`).

## Рассмотренные варианты

| Вариант | Почему не он |
|---|---|
| Пояснения в коде рядом с разбором | пересборка на каждое пояснение, условия под проекты, текст не проверить машиной |
| Пояснения из `--help` и man во время работы | медленно, по-английски, нужна установленная программа; оставлено как дополнение («Спросить у программы») |
| Пояснения от языковой модели | нужен интернет и ключ, ответ каждый раз разный и непроверяемый |

## Последствия

- Новая программа или урок - правка JSON без знания Rust (агент `kb-author`).
- Правила подкоманд пишутся регулярками JS и компилируются лениво, только
  для встреченных программ - иначе старт стоил бы сотни мс. Крейт regex,
  fancy-regex - только для правил с заглядыванием (`docs/optimizations.md`).
- Новый урок требует строки в `knowledge/lessons.json` - список намеренно
  закрытый, `validate.mjs` не пропустит опечатку в `topic`.
