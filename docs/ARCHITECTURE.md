# Устройство Пульта

Сверено с деревом 14.10.2026. Меняется вместе с кодом (правило ноль в `CLAUDE.md`).

## Слои

```
                knowledge/*.json  (база знаний: программы, уроки, эффекты, этапы, тексты)
                       │  kb.rs: с диска, иначе копия, вшитая в exe
                       ▼
┌──────────────────────────── core (pult-core) ────────────────────────────┐
│ scan.rs → explain.rs → topics.rs        git.rs   ci.rs + ci_config.rs   │
│ runner.rs (процессы без оболочки)   store.rs (настройки, история, кэш)  │
│ helpcmd.rs (--help)   env.rs (программы, Docker)   paths.rs   util.rs   │
│ ai.rs (ИИ-часть проекта: детали, связи, рассказ)                        │
└───────────────┬──────────────────────────────────────────┬──────────────┘
                │                                          │
   app (pult-app, Tauri 2)                       cli (pult-cli, ratatui)
   src/main.rs: команды IPC, события,            src/main.rs: экран и команды
   слежение за файлами (notify)                  info, ls, explain, run, ci, learn, ai, ui
   src/tray.rs: трей, сценарии, размер окна
                │ IPC (invoke / emit)
   ui/ (WebView2): titlebar.js, app.js, blocks.js, learn.js, scenarios.js, widget.js, statusbar.js
```

Окно (`ui/`): `app.js` - всё окно и общие помощники (состояние `S`, `call`,
`esc`, перерисовка `patch`, оценка «сколько ещё»); `learn.js` - уроки и
подсказки к терминам; `blocks.js` - блоки страниц: реестр `Blocks.register`, сетка,
перестановка, свёртка, скрытие (порядок - в localStorage); `scenarios.js` - вкладка «Сценарии» и её события;
`widget.js` - виджет (окно меньше 360 x 300); `ai.js` - вкладка «ИИ» (схема слоёв, рассказ, блоки видов деталей; подключается после `app.js`); `statusbar.js` - строка
состояния; `titlebar.js` - свой заголовок окна (окно без рамки Windows: перетаскивание,
свернуть, развернуть, закрыть) и запрет контекстного меню WebView, кроме полей ввода;
`theme.js` - тема до первой отрисовки. Высота заголовка - `--tbh`, высота рабочей области -
`--vh` (вместо `100vh`). Цвет фона самого окна повторяет тему (`window_bg`), чтобы при
изменении размера не было белых полос. Стили: `app.css`
(токены и элементы), `layout.css` (каркас, сетка, нижняя панель), `learn.css`,
`scenarios.css`, `widget.css`, `statusbar.css`. Три последних файла
скриптов подключаются после `app.js` и берут его помощники.

Ядро не знает про Tauri и ratatui. Оболочки только зовут функции ядра и
показывают результат (`docs/adr/0001-tauri-rust.md`).

## Путь данных

1. **Папка.** Пользователь выбирает папку (диалог, перетаскивание, аргумент
   командной строки, второй запуск ярлыка через single-instance).
2. **scan** (`scan::scan`). Собирает скрипты из `package.json`, `Makefile`,
   `justfile`, `Taskfile` и файлов-скриптов (форматы файлов разбирает код,
   смысл берётся из базы), добавляет стандартные команды для найденных
   манифестов (`Cargo.toml`, `*.csproj`, `docker-compose.yml`... по
   `manifests.json`), определяет стек
   (`stacks.json`), этап каждого скрипта (`stages.json`), документы корня,
   состояние (`health`), git и CI-конфиги. UNC-пути отвергаются, `.env`
   только проверяется на наличие.
3. **explain** (`explain.rs`). Для каждого скрипта: команда по частям, что
   делает, эффекты, ключи, «что внутри». Источники по порядку: база знаний
   (`src=kb`), шапка файла скрипта (`file`), `package.json` программы в
   `node_modules` (`package`). Правила подкоманд компилируются лениво,
   только для встреченных программ.
4. **topics** (`topics::detect`). Какие уроки нужны проекту, по `detect`
   каждого урока.
   **ai** (`ai::build`, отдельно от разбора, по запросу вкладки «ИИ» или `pult ai`). Один обход
   дерева (без `skipDirs`, ссылок и `walkSkip`), файлы по шаблонам `knowledge/ai.json` читаются
   как markdown с шапкой, JSON настроек, скрипты или джобы CI. Связи между деталями берутся
   только из текста; ничего из проекта не запускается, `.env*` не читаются, секреты скрыты.
   В `Project` лежит только `aiMarkers` (есть ли вообще ИИ-часть): по нему вкладка показывается
   или прячется.
5. **Кэш.** Результат пишется в `%LOCALAPPDATA%\dev.dotnotfact.pult\data\cache`;
   повторное открытие показывает кэш сразу, свежий разбор идёт фоном.
6. **Показ.** Окно получает `Project` ответом `scan_project` и событием
   `project`; терминал печатает его сам.

Запуск скрипта: `run` → `runner::spawn_live` (программа и аргументы списком,
Job Object на Windows) → вывод пачками раз в 50 мс событием `log` →
завершение событием `run` → запись в историю (`store`).

## Команды IPC (`app/src/main.rs`, `generate_handler!`)

| Команда | Что делает |
|---|---|
| `state` | недавние проекты, настройки, идущие запуски, база знаний для окна, версия |
| `kb_reload` | перечитать базу с диска |
| `topic` | один урок целиком |
| `scan_project` | разобрать папку (из кэша или заново), включить слежение |
| `ai_map` | карта ИИ-части проекта: из кэша сразу и пересборка в фоне, иначе собирается здесь; событие `ai` приходит, когда карта изменилась |
| `pick` | диалог выбора папки |
| `env_info` | есть ли программы, жив ли Docker |
| `help` | спросить у программы `--help` и разобрать ключи; программа из проекта - только с `confirmed` (полный путь, который человек подтвердил) |
| `trust_repo` | доверить репозиторий, в `.git/config` которого есть исполняемые настройки (фильтры, gpg, include) |
| `run`, `restart`, `stop` | запустить скрипт, перезапустить, остановить дерево процессов |
| `stdin` | строка или конец ввода для идущего процесса |
| `run_log`, `forget` | вывод запуска; забыть запуск |
| `history`, `history_clear` | история запусков проекта |
| `settings` | изменить настройки (патч) |
| `fav`, `recent` | избранные скрипты; недавние проекты (убрать, закрепить) |
| `ci_runs`, `ci_jobs`, `ci_log` | пайплайны, джобы, журнал джобы (через `glab`/`gh`, только доверенные хосты, с кэшем) |
| `open` | ссылка http(s), проводник, терминал, редактор, документ - только внутри проекта |
| `scenarios`, `scenarios_running` | все сценарии; id идущих сейчас (`app/src/tray.rs`) |
| `scenario_save`, `scenario_delete` | сохранить сценарий (новый получает id), удалить; меню трея пересобирается |
| `scenario_run`, `scenario_stop` | запустить шаги по очереди в фоне; остановить идущий сценарий |
| `window_set` | размер окна, по центру или нет, поверх всех окон (виджет и «Рекомендованный размер»); окно с новым размером остаётся в рабочей области экрана |
| `window_bg` | цвет фона самого окна `#rrggbb` под тему: без белых полос при растягивании |
| `mouse_down` | зажата ли кнопка мыши (`GetAsyncKeyState`): виджет включается только после того, как край окна отпустили |

`ci_runs` отдаёт у пайплайна `createdAt`, `startedAt`, `updatedAt`, `ci_jobs` у
джобы - `startedAt` и `duration`: по ним окно считает «сколько ещё».

## События (ядро → окно)

| Событие | Когда |
|---|---|
| `run` | запуск начался, сменил состояние, завершился |
| `log` | пачка вывода запуска |
| `project` | фоновый разбор нашёл изменения (`reason`: почему перечитан) |
| `project-error` | фоновый разбор упал |
| `git` | изменилось только состояние git |
| `ai` | пересобрана карта ИИ-части и она изменилась: `path`, `data` (правка файла детали пересобирает только её, без нового разбора проекта) |
| `open-path` | второй запуск ярлыка передал папку |
| `scenario` | сценарий начал шаг или закончился: `id`, `name`, `step`, `total`, `status` (`running`, `ok`, `fail`, `stopped`), `msg`, `runId` шага |

Окно ещё слушает `tauri://drag-drop` (перетаскивание папки).

## Где что хранится

| Что | Где |
|---|---|
| База знаний | `knowledge/` рядом с exe или выше по дереву (`PULT_HOME`), иначе копия в exe |
| Настройки, недавние, избранное, сценарии | `%LOCALAPPDATA%\dev.dotnotfact.pult\data\config.json` |
| История запусков | `...\data\history.json` |
| Кэш разбора, карты ИИ-части и CI | `...\data\cache\` (`scan-*.json`, `ai-*.json`, `ci.json`) |

`PULT_DATA` переопределяет папку данных. Почему не рядом с программой -
`docs/decisions.md`.
