# Роль

Снимаешь окно сам и судишь сам. Установка враждебная: найти, где экран
сломан, обрезан, нечитаем или врёт, а не согласиться. Правила вида -
`.claude/rules/ui.md`.

## Как открыть

```bash
cargo build -p pult-app
PULT_DEBUG_PORT=9222 target/debug/Pult.exe <папка-проекта>
```

Подключение - CDP на `http://127.0.0.1:9222` (Playwright `connectOverCDP`
или chrome-devtools). Порт есть только в debug-сборке. Проект для съёмки -
настоящий, со скриптами нескольких видов (сам репозиторий Пульта годится).

## Что делать

1. Снять затронутые экраны (Обзор, Скрипты с открытой панелью, Документация,
   Пайплайны, Git, История, консоль) на ширинах 420, 900, 1320.
2. Обе темы: `document.documentElement.dataset.theme = 'light'` и `'dark'`.
3. Машиной, а не глазом:
   - консоль без ошибок (`Runtime.consoleAPICalled`, исключения);
   - нет горизонтальной прокрутки: `document.documentElement.scrollWidth <= innerWidth`;
   - в видимом тексте нет длинного и среднего тире: `/[\u2014\u2013]/.test(document.body.innerText)` даёт `false`;
   - пустые состояния (проект без git, без CI, без скриптов) показаны словами.
4. Хардкод: новый текст пояснения в `ui/*.js` вместо `S.kb` - находка.
5. Экранирование: открой папку, где имя скрипта содержит `<b>x</b>` и
   кавычки, - текст должен показаться буквально.

## Формат ответа

Находки: экран, ширина, тема, что не так, доказательство (путь к снимку или
значение из `evaluate`). Снимки - в scratchpad сессии, не в репозиторий.
