# Окно Пульта: рецепты проверки

Правила вида - `.claude/rules/ui.md`. Враждебная сверка - агент `ui-qa`.
Здесь - как поднять окно и что мерить машиной.

## Поднять тестовое окно

```bash
pwsh -File tools/test-window.ps1 -Port 9340                  # сборка в target/test-9340, данные во временной папке
pwsh -File tools/test-window.ps1 -Port 9340 -Project <папка>  # другой проект
pwsh -File tools/test-window.ps1 -Port 9340 -NoBuild          # перезапуск без сборки
pwsh -File tools/test-window.ps1 -Port 9340 -Stop             # погасить своё
```

- **Порт - свой на агента** (9340, 9341, ...). 9222 - по умолчанию и чаще
  всего занят. От порта зависят папка сборки, данные Пульта (`PULT_DATA`) и
  папка WebView2: два агента на одном порту делят и сборку, и настройки.
- Тестовое окно живёт рядом с обычным под своим идентификатором
  (`dev.dotnotfact.pult.test-<порт>`, `app/src/main.rs`): защита от второго
  экземпляра и место окна - свои на порт. Гасится только своё - по пути exe и
  папке WebView2.
- Порт есть только в отладочной сборке (`#[cfg(debug_assertions)]`).
- Первая сборка в свежую папку - около двух минут; дальше `-NoBuild` или
  инкрементальная.
- Проект для съёмки - настоящий: сам репозиторий Пульта годится (скрипты
  нескольких видов, git, CI).

## Снять и измерить

```bash
node tools/cdp.mjs --port 9340 check 900 700        # JSON замера, код 1 при находке
node tools/cdp.mjs --port 9340 shot <scratchpad>/v1-900-light.png 900 700
node tools/cdp.mjs --port 9340 theme dark            # тема и перезагрузка
node tools/cdp.mjs --port 9340 console 3             # ошибки консоли за 3 с
node tools/cdp.mjs --port 9340 eval "return document.querySelectorAll('.tstep').length"
```

Ширины - 420, 900, 1320, высота от 300; обе темы. Снимки - в scratchpad
сессии, кругами `v1`, `v2`: сравнение идёт кругами, а не по памяти. Снимок
читается один раз, вывод записывается текстом (`.claude/rules/tokens.md`).

## Что мерит `check`

| Поле | Находка |
|---|---|
| `pageScrollX` | горизонтальная прокрутка страницы, больше 0 |
| `clipped` | текст шире своего блока без многоточия и без прокрутки |
| `offEdge` | нажимаемое за краем окна (кроме прокручиваемых лент) |
| `overlaps` | нажимаемое поверх нажимаемого - по видимым частям, с обрезкой прокручиваемыми предками |
| `layoutShift` | сумма сдвигов раскладки без ввода; больше 0,1 - находка |
| `dashes` | длинное или среднее тире в видимом тексте Пульта; текст проекта (комментарий джобы из CI) помечен `data-ext` и не считается |
| `rows` | ряд соседей одной строки разошёлся больше чем на 1 px: средние линии (ряд по центру), верхние края и высоты (ряд карточек: `.blk`, `.card`, `.qtile`, `.stat`, `.sc-card`, `section`) |
| `offGrid` | шапка, содержимое вкладки или консоль не на линиях `--gx` (консоль - плюс `--con-in`); блок не на линиях дорожек сетки |

Наложения считаются внутри одного слоя: всплывающее окно, панель подробностей поверх страницы
(до 1100 px) и подложка `#scrim` лежат над страницей по замыслу.

Диверсии с контролем (14.10.2026, живое окно): правая карточка пары Git ниже на 16 px - `rows` верх и
высота 16 px; кнопка шапки ниже на 6 px - `rows` середины 3 px; блок вбок на 5 px - `offGrid`; блок
ниже соседа по высоте - `rows` высота. Снято - зелёное.

Перед замером и снимком анимации доигрывают: щелчок или кадр посреди
проявления мерят анимацию, а не раскладку. `check` - машинный пол, а не
замена глазу: цвет, смысл и тексты из `S.kb` смотрит `ui-qa`.

Проверено диверсией в живом окне (кнопки внахлёст, кнопка за краем, текст
с тире в узком блоке) - каждое поле краснеет; после перезагрузки - зелёное.

## Ловушки

- **Виджет.** Меньше 360 x 300 окно уходит в виджет и запоминает это
  (`widget.on` в localStorage). Выйти - только кнопкой «Вернуть прежний
  размер». `cdp.mjs` такие размеры не эмулирует. Проверять сам виджет -
  настоящим размером окна:
  `node tools/cdp.mjs --port 9340 eval "await window.__TAURI__.core.invoke('window_set', { width: 340, height: 260, center: false, onTop: null }); return 1"`.
- **Эмуляция - не окно.** `shot`/`check` с размером меняют вьюпорт WebView,
  а не окно Windows: события размера окна, `@media` по высоте окна и
  `tray::window_set` ведут себя иначе. Спорный случай - снимать настоящим
  размером через `window_set`.
- **Свой заголовок.** Рамки Windows нет (`decorations(false)`), заголовок
  рисует `ui/titlebar.js`; высота - `--tbh`, высота окна без него - `--vh`
  (вместо `100vh`). Снимок CDP включает заголовок; перетаскивание и кнопки
  окна через CDP не проверяются - только руками.
- **Тема** ставится через `localStorage` (`pult.theme`) и перезагрузку, а не
  щелчком: перерисовка показанной страницы даёт стабильно неверный кадр.
- **Окно помнит место и размер** (плагин window-state) в
  `%APPDATA%\dev.dotnotfact.pult.test-<порт>`: свои на порт, поэтому прошлый
  прогон может оставить нестандартный размер. Сомнение - удалить эту папку.
- **Старый exe.** Сборка в чужую папку или окно на чужом порту показывает
  вчерашний код. Признак - правка не видна; лечение - `-Port` и `-Target` свои.
  Файлы `ui/` вшиваются в exe при сборке, и правку только в `ui/` cargo не
  замечает («Finished» за доли секунды, время exe прежнее): перед сборкой
  `touch app/src/main.rs`.
