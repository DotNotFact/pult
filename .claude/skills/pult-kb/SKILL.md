# База знаний: рецепты

Правила - `.claude/rules/knowledge-base.md`, формат - `knowledge/SCHEMA.md`.
Здесь только «как».

## Добавить программу

1. Есть ли она уже:

   ```bash
   grep -rn '"bins"' knowledge/tools | grep -i '<имя>'
   ```

2. Выбрать файл по теме (`knowledge/tools/node.json`, `rust.json`,
   `docker.json`...) и дописать объект по образцу соседнего:

   ```json
   {
     "id": "taplo",
     "name": "Taplo",
     "topic": "rust",
     "bins": ["taplo"],
     "about": "Программа, которая проверяет и выравнивает файлы TOML.",
     "how": ["Читает файлы .toml", "Сверяет их со схемой", "Печатает ошибки или переписывает файл ровно"],
     "default": { "say": "Проверяет файлы TOML", "fx": ["read"] },
     "sub": [
       { "match": "^(fmt|format)\\b", "part": "выравнивание", "say": "Выравнивает файлы TOML", "fx": ["write"] }
     ],
     "flags": [
       { "flag": "--check", "text": "Только проверить, ничего не менять", "fxRemove": ["write"] }
     ],
     "help": "--help"
   }
   ```

3. Проверить файл и всю базу:

   ```bash
   node knowledge/validate.mjs tools/rust.json
   node knowledge/validate.mjs
   ```

## Добавить урок

1. Скопировать соседний `knowledge/topics/<похожий>.json` в
   `topics/<id>.json`, заменить `id`, `title`, `color`, `icon`, `summary`,
   `detect`, `sections`.
2. Дописать `<id>` в `knowledge/lessons.json` (поле `order`) на нужное место.
3. Секция `project` - без полей кроме `title`: её заполняет Пульт.
4. `node knowledge/validate.mjs topics/<id>.json`.

## Проверить на настоящем проекте

```bash
cargo run -p pult-core --example scan --release -- <папка> <скрипт>
```

Печатает время загрузки базы, число скриптов и сколько распознано, стек,
уроки, git, CI и разбор каждого скрипта. Второй аргумент - часть имени
скрипта: для него ещё `argv` и команда по частям. Новая программа должна
дать `src=kb` и непустое `tools=[...]`; `src=file` или `src=package` значит,
что база её не узнала и объяснение собрано из шапки файла или пакета.

Проверка в окне без пересборки: настройки, «База знаний» - «Перечитать»,
затем F5. Из терминала - `pult explain <скрипт>` в папке проекта.

## Частые ошибки

| Признак | Причина |
|---|---|
| `topic: нет такого урока` | id урока не в `lessons.json` (поле `order`) или опечатка |
| `длинное или среднее тире` | в тексте U+2014 или U+2013; заменить на «-» |
| `вода: «...»` | запрещённое слово из `BAD_WORDS` в `validate.mjs` |
| Подкоманда не узнаётся | `match` сравнивается с текстом ПОСЛЕ `bins`, а не со всей командой |
| Узнаётся чужая подкоманда | нет `\\b` в конце `match` |
