# ADR 0001 - Пульт 2.0 на Rust: ядро, окно Tauri 2, терминал ratatui

**Статус:** принято владельцем 13.10.2026 · **Затрагивает:** весь репозиторий

## Контекст

Пульт держат открытым весь день рядом с редактором и браузером. Он
запускается часто (ярлык, `pult` в терминале) и разбирает папки на сотни
скриптов. Значит, важны память в простое, время до первого окна и скорость
разбора. Нужны два лица - окно и терминал - с одинаковыми объяснениями.

## Решение

1. **Ядро `pult-core` на Rust** - вся логика: разбор, объяснения, git, CI,
   процессы, хранилище.
2. **Окно - Tauri 2** поверх системного WebView2: интерфейс на HTML/JS из
   `ui/`, связь с ядром через IPC Tauri, без сервера и порта.
3. **Терминал - ratatui** в отдельном `pult-cli.exe` на том же ядре.
4. Workspace из трёх крейтов: `core`, `app`, `cli`.

## Рассмотренные варианты

| Вариант | Цена | Почему не он |
|---|---|---|
| Node + Electron | свой Chromium в каждой копии, сотни МБ памяти, медленный старт | память и старт - главное требование |
| Node, окно через браузер и локальный сервер | открытый порт, отдельная страница | порт - лишняя поверхность атаки, два процесса |
| .NET (WPF или Avalonia) | рантайм, второй язык для терминала | отказ владельца; WPF только Windows |
| **Rust + Tauri 2 + ratatui** | один язык, WebView2 уже в системе | выбрано |

## Последствия

- Exe маленький, база знаний вшита копией и читается с диска для правок без
  пересборки.
- Окно зависит от WebView2: на Windows 10/11 он есть, на голой системе
  нужен установщик (см. `TODO.md`).
- Linux и macOS собираются в теории (`cfg(windows)` разделяет код), но не
  проверялись.
