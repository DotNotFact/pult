# Ядро и оболочки на Rust

## Границы

- `core` не знает про Tauri и ratatui. Всё, что нужно обоим, - здесь.
- `app/src/main.rs` - команды IPC, события, слежение за файлами, пачки
  вывода. Никакого разбора проекта и объяснений. `app/src/tray.rs` - трей,
  сценарии (хранит их `store`), размер и фон окна.
- `cli/src/main.rs` - экран и команды терминала поверх тех же функций ядра.
- Правка нужна и окну, и терминалу - она в `core`. Две копии одной логики в
  `app` и `cli` - дефект.
- Модуль - один предмет: разбор (`scan`), объяснение (`explain`), процессы
  (`runner`), хранилище (`store`). Новый предмет - новый модуль и строка в
  карте `CLAUDE.md`.

## Знания не в коде

Строка-пояснение, слово-признак, список программ или расширений в `.rs` -
дефект. Это поле в `knowledge/*.json`, ядро читает его через `kb::get()`
(`str_list`, поля `Tool`, `Desc`). Сообщения об ошибках самого Пульта
(«Проект не открыт») - не знания, они могут жить в коде.

## Без оболочки

Процессы - только через `runner` (`spawn_live`, `capture`, `capture_env`,
`run_inherit`), программа и аргументы списком. Системные действия
(открыть файл, показать в проводнике, редактор, терминал, остановка дерева)
тоже живут в `runner` (`open_default`, `reveal`, `open_in_editor`,
`open_terminal`). `Command::new` за пределами `runner` - только запуск
своего же `Pult.exe` из терминала (`cmd_ui`). git - только через `git.rs` с
набором `SAFE`. Подробно - `security.md`.

## Скорость

- Регулярки из кода - `crate::re!(r"...")`: компилируются один раз за запуск.
  `Regex::new` в цикле или в функции, которую зовут на каждый скрипт, -
  дефект.
- Регулярки из данных - `util::cached_re(pattern)`: кэш по тексту выражения.
- Правила подкоманд (`sub[].match`, синтаксис JS) - fancy-regex, лениво
  (`SubRule::re()` через `OnceLock`, лимит перебора 100 000) и только для программ, которые встретились
  в проекте. Не компилировать всю базу при старте.
- Внешние программы - с таймаутом (`capture` принимает `Duration`).
- Замер - `cargo run -p pult-core --example scan --release -- <папка>`
  (печатает время базы и разбора) и `--example prof`. Ускорение называется
  числом до и после. Полный замер (части разбора, память, размеры IPC) -
  `--example perf`, результаты и метод - `docs/optimizations.md`.

## Гейты

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

`unwrap()` на данных пользователя (файл проекта, вывод программы) - нет;
на своих инвариантах (регулярка в коде) - допустим с `expect("...")`.
