# ADR 0004 - Установщик: NSIS на одного пользователя

**Статус:** принято владельцем 14.10.2026 · **Затрагивает:** `app/tauri.conf.json`
(раздел `bundle`), `app/installer/`, `tools/build-installer.ps1`,
`tools/package.ps1`, `.github/workflows/release.yml`

## Контекст

До 2.0.0 Пульт ставили так: скачать zip, распаковать, запустить `Pult.exe`.
Ярлыка в меню «Пуск» нет, в «Установленных приложениях» Пульта нет, `pult`
в терминале работает только из папки архива, а убрать Пульт целиком можно,
только зная, где он хранит данные. Нужна установка «скачал и запустил», без
прав администратора, с понятным удалением и без потери настроек при
обновлении.

## Решение

1. **NSIS из Tauri, установка на одного пользователя.** `bundle.targets` -
   `nsis`, `installMode` - `currentUser`: окна UAC нет, программа ложится в
   `%LOCALAPPDATA%\Programs\Pult` - папку программ пользователя, которую
   Windows для этого и заводит. Tauri по умолчанию кладёт в
   `%LOCALAPPDATA%\Pult`; папку меняет хук (`app/installer/hooks.nsh`).
   Ключ `/D=путь` выбирает другую папку, повторная установка находит прошлую.
2. **Состав:** `Pult.exe`, `pult-cli.exe`, `bin\pult.cmd`, `uninstall.exe`.
   `pult.cmd` лежит в `bin\` один: в PATH идёт эта папка, а не папка
   программы. Рядом с `Pult.exe` команда `pult` открыла бы окно - `PATHEXT`
   ставит `.EXE` раньше `.CMD`. Тот же `bin\pult.cmd` - в zip.
   Терминальная версия и обёртка едут ресурсами Tauri из отдельного файла
   настроек `app/installer/tauri.installer.json`: в `tauri.conf.json` их
   положить нельзя, иначе обычная `cargo build` окна требовала бы готовый
   `pult-cli.exe`. Папки `knowledge\` в установке нет: работает копия базы,
   вшитая в exe, - она всегда той же версии, что и программа.
3. **Ярлыки и языки.** Ярлык в меню «Пуск» ставится всегда, на рабочем столе -
   флажком на последней странице. Язык установщика - русский или английский,
   по языку Windows. Картинки страниц - `app/installer/*.bmp`, их рисует
   `tools/installer-art.ps1` из логотипа.
4. **PATH по флажку.** На первой странице флажок «Добавить команду pult в
   PATH» (стоит по умолчанию); в тихой установке - ключ `/ADDTOPATH`. В PATH
   добавляется `%LOCALAPPDATA%\Programs\Pult\bin`. Выбор помнится в
   `HKCU\Software\DotNotFact\Pult`, обновление его повторяет.
   Правится только PATH пользователя (`HKCU\Environment`), только своя
   запись, тип `REG_EXPAND_SZ` и `%ПЕРЕМЕННЫЕ%` сохраняются. Правит его
   `app/installer/pult-setup.ps1`, а не сам NSIS: строка NSIS из Tauri
   ограничена 1024 знаками, а PATH разработчика часто длиннее, и обрезанный
   PATH сломал бы чужие программы. Если PowerShell запрещён политикой, PATH
   остаётся как был, а в журнале установки - строка об этом.
5. **WebView2 - `embedBootstrapper`.** Загрузчик WebView2 от Microsoft
   (около 2 МБ) лежит внутри установщика и запускается, только если WebView2
   на машине нет. В Windows 11 он есть всегда, в Windows 10 - почти всегда.
6. **Данные - вне папки программы, обновление их не трогает:**

   | Что | Где |
   |---|---|
   | настройки, недавние, избранное, история, кэш разбора | `%LOCALAPPDATA%\dev.dotnotfact.pult\data` (`core/src/paths.rs`) |
   | данные WebView2 окна | `%LOCALAPPDATA%\dev.dotnotfact.pult\EBWebView` (Tauri 2 берёт `app_local_data_dir`) |
   | размер и место окна | `%APPDATA%\dev.dotnotfact.pult\.window-state.json` (`tauri-plugin-window-state`) |

   Переносная версия из zip пишет туда же: zip и установщик можно менять
   местами без потери настроек.
7. **Удаление.** Перед установкой и удалением закрываются `Pult.exe` и
   `pult-cli.exe`, запущенные из папки установки; Пульты из других папок не
   трогаются. Удаление спрашивает «Удалить также настройки, историю и кэш
   Пульта?» (по умолчанию - «Нет»). «Да» удаляет обе папки из таблицы выше
   и ключ `HKCU\Software\DotNotFact\Pult`, «Нет» оставляет их: новая
   установка вернёт всё как было. Тихое удаление (`/S`) данные оставляет,
   `/S /WIPEDATA` удаляет. Перед удалением данных останавливается WebView2
   закрытого окна: он живёт ещё минуты после Pult.exe и пишет в
   `EBWebView`, и удалённая папка появлялась снова (найдено проверкой
   14.10.2026). WebView2 Пульта, запущенного из другой папки, не трогается -
   тогда удалятор говорит, какую папку удалить руками. Если на первой
   странице удаления поставить флажок «Удалить данные приложения» (его
   рисует шаблон Tauri), вопрос не задаётся. Удаление прошлой версии, которое запускает сам
   установщик при обновлении, вопроса не задаёт. В любом случае уходят:
   файлы программы, ярлыки, запись в «Установленных приложениях», своя
   запись в PATH, автозапуск, если он был, и записи значка в трее
   (`HKCU\Control Panel\NotifyIconSettings`).
8. **Подписи нет**, сертификата пока нет. Место для неё готово: Tauri
   подписывает exe, установщик и удалятор командой из
   `bundle.windows.signCommand`, а `tools/build-installer.ps1 -SignCommand`
   передаёт её без правки `tauri.conf.json`.
9. **Версия Tauri CLI закреплена** в `tools/build-installer.ps1`: хуки
   встают в шаблон NSIS из этой версии.

## Рассмотренные варианты

| Вариант | Почему не он |
|---|---|
| MSI (WiX) | Tauri ставит MSI на всю машину: UAC и `Program Files`. Своего вопроса при удалении WiX-шаблон Tauri не даёт |
| NSIS `perMachine` или `both` | права администратора ради программы, которой пользуется один человек |
| WebView2 `downloadBootstrapper` | установщик меньше на 2 МБ, но сам качает загрузчик по ссылке: лишний сетевой шаг до кода Microsoft, который умеет прокси и повторы |
| WebView2 `offlineInstaller` | плюс 180 МБ к установщику ради редкой машины без WebView2 и без интернета |
| PATH средствами NSIS (`ReadRegStr` и разбор строки) | строка NSIS - 1024 знака; на длинном PATH правку пришлось бы пропускать, а ошибка в разборе обрезала бы PATH целиком |
| Свой шаблон NSIS целиком (`nsis.template`) | тысяча строк чужого шаблона в репозитории и ручное слияние на каждом обновлении Tauri. Хуки трогают шаблон в трёх местах, и два из трёх при расхождении роняют сборку |
| `knowledge\` рядом с exe в установке | две копии базы; тихое обновление поверх оставляло бы удалённые файлы старой версии, и они подменяли бы новую базу |
| Данные рядом с программой | удаление и обновление стирали бы настройки, а запись в папку программы - не место для данных |

## Последствия

- Новая версия `@tauri-apps/cli` - сверить три места «ШАБЛОН» в
  `app/installer/hooks.nsh` с новым `installer.nsi`; `build-installer.ps1`
  проверяет переменные шаблона и падает, если их нет.
- `pult-cli.exe` собирается с библиотекой `VCRUNTIME140.dll` из Visual C++
  Redistributable (окно - без неё: `tauri-build` собирает рантайм статически).
  На машине без Redistributable `pult` не запустится; `build-installer.ps1`
  предупреждает об этом при каждой сборке. Лечится статической сборкой
  рантайма в `cli` (`static_vcruntime` в `cli/build.rs` или
  `+crt-static` для цели `x86_64-pc-windows-msvc`).
- Пока нет подписи, SmartScreen предупреждает при первом запуске
  скачанного установщика.
- Порядок проверки установщика руками - `.claude/rules/release.md`.
