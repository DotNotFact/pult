# Решения владельца

Одна строка - одно решение. Формат: **дата · тема · решение · обратимо/нет ·
где применено**.

**Прежде чем спрашивать владельца - `grep` по этому файлу.** Есть запись -
не спрашивать. Отменённое решение зачёркивается рядом, а не стирается:
grep должен находить и прежнее решение, и его отмену.

Этот файл не заменяет ADR. `docs/adr/` объясняет архитектурное решение
целиком, с отвергнутыми вариантами. Здесь - строка, по которой ищут.

## Платформа

- 13.10.2026 · стек · Пульт 2.0 на Rust: ядро `pult-core`, окно Tauri 2 +
  WebView2, терминал ratatui. Отказ от Node (Electron) и .NET ради памяти и
  скорости запуска · необратимо без переписывания · `docs/adr/0001-tauri-rust.md`
- 13.10.2026 · две оболочки · окно и терминал - тонкие оболочки над одним
  ядром, логика одинаковая для обоих · обратимо · `CLAUDE.md`, правило 3
- 13.10.2026 · данные пользователя · настройки, история и кэш живут в
  `%LOCALAPPDATA%\dev.dotnotfact.pult\data`, а не рядом с программой:
  обновление и удаление программы их не трогают, в репозиторий они не
  попадают. Старая папка `data/` один раз переносится · обратимо ·
  `core/src/paths.rs`
- 14.10.2026 · установка · основной способ - установщик NSIS на одного
  пользователя без прав администратора в `%LOCALAPPDATA%\Programs\Pult`,
  переносный zip остаётся. Удаление спрашивает про настройки, историю и
  кэш, тихое удаление их оставляет (`/WIPEDATA` - удаляет) · обратимо ·
  `docs/adr/0004-installer.md`
- 14.10.2026 · репозиторий · GitHub, ПУБЛИЧНЫЙ, `DotNotFact/pult`, open source
  под MIT (решение владельца 14.10.2026, отменяет «приватный» от 13.10). Автор
  коммитов только `DotNotFact`, без `Co-Authored-By` и строки «Generated
  with Claude Code» · обратимо · `CLAUDE.md`, рабочий цикл

## Знания и тексты

- 13.10.2026 · хардкод · знания только в `knowledge/*.json`: пояснения,
  слова-признаки этапов, стандартные команды манифестов, подсказки. Ни одного
  правила под конкретный проект; владелец «сильно презирает хардкод» ·
  необратимо · `docs/adr/0002-knowledge-as-data.md`
- 13.10.2026 · тире · в текстах только дефис «-»; длинное и среднее тире
  запрещены везде: база, интерфейс, документы, коммиты. Проверка -
  `validate.mjs` и `LC_ALL=C.UTF-8 grep -rP "[\x{2014}\x{2013}]"` · обратимо ·
  `knowledge/SCHEMA.md`, `CLAUDE.md`, правило 4
- 13.10.2026 · стиль текста · русский, простые слова для новичка, без воды
  и ИИ-оборотов («давайте разберёмся», «важно отметить», «мощный»,
  «является») · обратимо · `knowledge/validate.mjs`, `BAD_WORDS`
